# 대출 계산기 (Loan Calculator)

대출 원금·연이자율·기간을 입력하면 상환 방식별 월 상환 스케줄과 총 이자를 계산해주는 웹 앱입니다.

**라이브 데모:** https://loan-calculator-rho-livid.vercel.app

## 기능

- 상환 방식 3종 지원
  - **원리금균등**: 매월 동일 금액 상환
  - **원금균등**: 매월 동일 원금 + 잔액 이자
  - **만기일시**: 매월 이자만 납부, 만기 원금 일시 상환
- 상환 방식 3종 비교 모드
  - 단일 방식 보기 ↔ 3종 비교 토글 (선택 상태 localStorage 저장)
  - 같은 조건으로 방식별 첫 달 납입금 / 마지막 회차 납입금 / 총 이자 / 총 상환액을 카드로 나란히 비교
  - 총 이자가 가장 적은 방식 하이라이트
  - 월 납입금 추이를 3개 라인으로 겹쳐 보여주는 비교 라인 차트
  - 비교 모드에서는 중도상환 미적용(기본 조건 비교)
- 중도상환(추가 상환) 시뮬레이션
  - 중도상환 시점(회차)·금액·수수료율(%) 입력
  - 상환 후 방식 선택: **기간 단축**(월 납입금 유지) / **월 납입금 감소**(기간 유지)
  - 전/후 비교 요약: 절감되는 총 이자, 단축 기간(또는 월 납입금 변화), 수수료, 순 절감액
- 월별 상환 스케줄 표 (납입금 / 원금 / 이자 / 잔액, 중도상환 회차 하이라이트)
- 요약 카드: 월 납입금, 총 이자, 총 상환액
- 차트: 원금 vs 이자 비중 도넛 차트, 월별 납입금 구성 스택 바 차트
- UX: 천 단위 콤마 입력, 슬라이더 병행 입력, 한글 금액 표기(억/만), localStorage 입력값 저장
- 다크 테마 반응형 UI

## 기술 스택

- Vite + React + TypeScript
- Tailwind CSS v4
- 순수 SVG 차트 (외부 차트 라이브러리 없음)

## 개발

```bash
npm install
npm run dev
npm run build
```

## 면책

본 계산기는 참고용이며 실제 대출 조건(중도상환수수료, 변동금리, 일할 계산 등)은 금융기관에 따라 다를 수 있습니다.
