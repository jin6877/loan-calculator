# 대출 계산기 (Loan Calculator)

대출 원금·연이자율·기간을 입력하면 상환 방식별 월 상환 스케줄과 총 이자를 계산해주는 웹 앱입니다.

**라이브 데모:** https://loan-calculator.vercel.app <!-- 배포 후 실제 URL로 교체 -->

## 기능

- 상환 방식 3종 지원
  - **원리금균등**: 매월 동일 금액 상환
  - **원금균등**: 매월 동일 원금 + 잔액 이자
  - **만기일시**: 매월 이자만 납부, 만기 원금 일시 상환
- 월별 상환 스케줄 표 (납입금 / 원금 / 이자 / 잔액)
- 요약 카드: 월 납입금, 총 이자, 총 상환액
- 차트: 원금 vs 이자 비중 도넛 차트, 월별 납입금 구성 스택 바 차트
- UX: 천 단위 콤마 입력, 슬라이더 병행 입력, 한글 금액 표기(억/만), localStorage 입력값 저장
- 다크 테마 반응형 UI

## 기술 스택

- Vite + React + TypeScript
- Tailwind CSS v4
- 순수 SVG 차트 (외부 차트 라이브러리 없음)

## 개발

```bash
npm install
npm run dev
npm run build
```

## 면책

본 계산기는 참고용이며 실제 대출 조건(중도상환수수료, 변동금리, 일할 계산 등)은 금융기관에 따라 다를 수 있습니다.
